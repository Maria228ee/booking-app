# Бронирование помещений

Проект: «Бронирование помещений» и консольная демонстрация.

## Модель

| Класс | Роль |
|-------|------|
| `RoomType` | Перечисление типов помещений (с полями и телом константы) |
| `TimeInterval` | record-интервал `[start, end)` с валидацией в компактном конструкторе |
| `Equipment` | Интерфейс оснащения с полиморфным методом `description()` |
| `Projector`, `Whiteboard` | Реализации `Equipment` (record) |
| `Room` | Помещение: номер, тип, вместимость, оснащение |
| `Employee` | Сотрудник: табельный номер + ФИО; equals/hashCode по номеру |
| `Booking` | Бронь: помещение + интервал + сотрудник; можно отменить |
| `BookingConflictException` | Собственное проверяемое исключение |
| `BookingService` | Операции: бронирование, отмена, свободные окна, подбор помещения |
